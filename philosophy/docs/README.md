# Philosophy Mapping Documentation

This directory contains comprehensive documentation for the philosophy mapping system.

## Documents

### [Rules & Axes](rules.md)
Complete guide to understanding and scoring philosophical rules on the 6 conceptual axes.

**Contents:**
- Rule structure and JSON schema
- Detailed axis definitions (Conflict, Truth, Order, Will, Risk, Time)
- Scoring guidelines and consistency tips
- Relationship types and patterns
- Common mistakes to avoid

### [Scripts Guide](scripts.md)
Technical documentation for each processing module.

**Contents:**
- Purpose and key functions for each script
- Data flow between modules
- Customization options
- Testing procedures
- Error handling and troubleshooting

### [Examples](examples.md)
Sample philosophical rules and common patterns.

**Contents:**
- Complete example rules (classical, modern, contemporary)
- Common philosophical patterns (Stoic, Pragmatic, Disruptive, etc.)
- Step-by-step guide for adding your first rule
- Scoring tips and consistency checks

## How to Use This Documentation

1. **Start with Rules & Axes** - Understand the scoring system before adding rules
2. **Review Examples** - See patterns and complete rule samples
3. **Reference Scripts** - Understand how processing works
4. **Iterate and Test** - Add rules incrementally and test results

## Documentation Philosophy

- **Modular** - Each document focuses on a specific aspect
- **Practical** - Emphasizes how-to guidance over theory
- **Comprehensive** - Covers both basic and advanced usage
- **Examples-driven** - Uses concrete samples to illustrate concepts

This documentation structure allows users to quickly find specific information while providing comprehensive coverage of the entire system.
